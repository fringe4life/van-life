At-rules

What can only be written as a rule rather than a declaration — and the one entry here that genuinely reshapes an installed face.

3 rules

A local() face with metric overrides

$3,486.50

$3,486.50

Metric Alias above, the stack alone below — the box height is the override

@font-face { font-family: "Metric Inter"; src: local("Arial"), local("Liberation Sans"), local("DejaVu Sans"), local("Segoe UI"); size-adjust: 100%; ascent-override: 90.2%; descent-override: 22.48%; line-gap-override: 0%; }

The one at-rule that genuinely customises a system face: reuse an installed font but replace its line box, so a fallback reserves Inter's height. Zero bytes, no download, and it is the real fix for the swap shift (#450).

@font-feature-values / font-variant-alternates

4021 shipped, 142 booked

Identical to the bare stack: no styleset registry to reach

@font-feature-values "System Numerals" { @styleset { open-four: 1; } } /* then */ .n { font-variant-alternates: styleset(open-four) }

Valid CSS, inert here. A system face exposes no styleset registry to the page, so this only pays off with a bundled OpenType family. Included because it is the syntax people reach for first.

text-box-trim behind @supports

Heading, untrimmed

Heading, trim-both

@supports (text-box-trim: trim-both) { .trim-cap { text-box-trim: trim-both; text-box-edge: cap alphabetic; } }

Trims the leading above cap height and below the baseline, so a 40px number can sit flush in its row without a negative margin. Chrome 133+ and Safari 18.2+; the @supports guard keeps the fallback honest.

Findings

  • The stack is a coverage claim, not a look. Five of the six sans names resolve on any one machine, and the six mono names collapse to one or two. What the pair buys is that each OS lands on a geometric face instead of its UI default; what it does not buy is the same face everywhere. The measured column above is the honest answer, and it changes per machine.
  • Weight coverage is the trade, and it is now paid three times over. 800 exists on Avenir and Montserrat only; Corbel stops at 700, URW Gothic at 600, source-sans-pro at 700. So display moved to bold, UI accents moved to medium, and font-synthesis: none went global: every weight is a real cut, never a smear. What that costs is rounding — Avenir answers 700 with 800, Corbel and source-sans-pro answer 500 with 400, URW Gothic answers anything under 600 with 300 — visible in the baseline column above.
  • Shadows work per glyph. text-shadow composites on the glyph outline, takes any number of layers, first layer on top. Under 1px and below 20% alpha it stops reading as a shadow and starts reading as weight.
  • Filters work per element. filter: drop-shadow() follows glyph alpha like a shadow, but it is one shadow, it rasterises, and it clips at the element's box.
  • Tracking does what a lighter weight cannot. A geometric face sets wider than Inter at the same size, so −0.022em on display and −0.006em on body is the cheapest correction available: no bytes, no extra paint, and it survives every platform.
  • Variable axes are closed. A face reached through a system name exposes no font-variation-settings and, in practice, no styleset registry. The one genuine hook is @font-face with src: local() plus size-adjust and the metric overrides.
